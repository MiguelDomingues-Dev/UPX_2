Só é necessário se você for rodar SEM o Maven (scripts executar.bat / executar.sh).

Baixe o driver oficial do MySQL para Java e coloque o arquivo .jar nesta pasta:
  https://repo1.maven.org/maven2/com/mysql/mysql-connector-j/8.4.0/mysql-connector-j-8.4.0.jar

(Com o Maven ou abrindo o projeto no IntelliJ, VS Code ou NetBeans, o driver é baixado sozinho.)
